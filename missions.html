MISSION PRINCIPALE · GTA V · TEST

Prologue

Lieu : Ludendorff, North Yankton (2004)
Personnages : Michael Townley, Trevor Philips, Brad Snider

Michael, Trevor et Brad braquent un dépôt de fonds à Ludendorff. Après avoir récupéré l'argent, ils tentent de fuir les forces de l'ordre. L'opération tourne mal.

Objectifs : maîtriser les otages, ouvrir le coffre, récupérer l'argent et tenter de rejoindre le point d'extraction.

Déroulement : le groupe rassemble les otages, déclenche les explosifs, récupère l’argent puis affronte la police lors de sa fuite. La mission se déroule neuf ans avant l’histoire principale.

Étapes principales : maîtriser les otages ; faire exploser la porte du coffre ; prendre l’argent ; sortir du dépôt ; rejoindre le véhicule ; tenter d’atteindre le point de récupération.
