Ajouter ou modifier une fiche

Les fiches sont publiées dans Cloudflare et visibles sur la page Personnages. Le jeton administrateur est demandé pour les modifications et n’est pas enregistré.

Importer les personnages

Importe plusieurs fiches à partir d’un fichier JSON ou colle un tableau JSON. Les fiches existantes (même nom et même catégorie) sont mises à jour ; les nouvelles sont ajoutées. Les champs vides du JSON ne remplacent pas les informations déjà enregistrées. Vérifie les informations avant publication : aucun article extérieur n’est aspiré automatiquement.
